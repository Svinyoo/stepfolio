# Stepfolio 1.1.0

- เพิ่มจุดเน้น / Step ได้หลายจุดต่อภาพ และเริ่มนับ 1 ใหม่ในแต่ละภาพ
- เพิ่มกรอบสี่เหลี่ยม ไฮไลท์ ข้อความ สี และขนาดตัวอักษร
- เลือกรายการเพื่อย้าย ลบ และจัดลำดับจุดเน้น
- บันทึกเครื่องหมายทั้งหมดในโครงการ ส่งออก PDF ได้ และเปิดโครงการรุ่นเดิมได้
- คู่มือภาษาไทยพร้อมภาพประกอบ 12 หน้า รวมในตัวติดตั้ง เปิดจากเมนู ช่วยเหลือ > คู่มือภาษาไทย

## ดาวน์โหลด

- Windows 10/11 x64: Setup สำหรับติดตั้ง, Portable สำหรับเปิดใช้งาน, ZIP สำหรับแตกทั้งโฟลเดอร์
- Mac Apple Silicon: ไฟล์ mac-arm64.dmg หรือ ZIP
- Mac Intel: ไฟล์ mac-x64.dmg หรือ ZIP
- คู่มือ: Stepfolio-User-Guide-TH-1.1.0.pdf

ก่อนอัปเดต ให้บันทึกโครงการแล้วปิดโปรแกรมเดิม ใช้รุ่น 1.1.0 เพื่อแก้ไขไฟล์ที่มีเครื่องหมายหลายรายการต่อภาพ

ไฟล์เผยแพร่ผ่านการทดสอบ editor, annotations, save/open และ PDF บนแอปที่แพ็กแล้วทั้งสามสถาปัตยกรรม Windows ผ่านการติดตั้ง Setup และทดสอบ native recording บน GitHub runner เพิ่มเติม การบันทึกจริงบน Mac ยังต้องอนุญาต Screen Recording และ Accessibility บนเครื่องผู้ใช้

รุ่นนี้ยังไม่มี code signing / notarization ระบบอาจแจ้งผู้เผยแพร่ไม่ทราบชื่อ มีไฟล์ SHA256SUMS สำหรับตรวจสอบไฟล์ดาวน์โหลด
