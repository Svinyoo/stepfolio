# Stepfolio

โปรแกรมบันทึกขั้นตอนบนหน้าจอและสร้างคู่มือ PDF สำหรับ Windows และ macOS

## ดาวน์โหลด Stepfolio 1.1.1

**เลือกภาพท้ายรายการได้ต่อเนื่องโดย scrollbar ไม่เด้งกลับบนสุด** รุ่นนี้คงตำแหน่งเลื่อนรายการภาพด้านซ้ายระหว่างเลือกภาพ แก้คำบรรยาย และจัดลำดับ ให้ผู้ใช้เลื่อนขึ้นลงเอง

ตัวติดตั้งรุ่น 1.1.1 กำลังสร้างและตรวจสอบ ดูความคืบหน้าที่ [GitHub Actions](https://github.com/Svinyoo/stepfolio/actions/workflows/build.yml?query=branch%3Amain) ไฟล์ดาวน์โหลดจะปรากฏในส่วน **Artifacts** เมื่อแต่ละแพ็กเกจผ่านการทดสอบ

| เครื่องที่ใช้งาน | ชื่อชุดดาวน์โหลดใน Artifacts | ไฟล์ติดตั้งภายใน |
| --- | --- | --- |
| Windows 10/11 x64 | Stepfolio-windows-x64 | `Stepfolio-Setup-1.1.1-x64.exe` |
| Mac Apple Silicon (M series) | Stepfolio-mac-arm64 | `Stepfolio-1.1.1-mac-arm64.dmg` |
| Mac Intel | Stepfolio-mac-intel | `Stepfolio-1.1.1-mac-x64.dmg` |

### วิธีดาวน์โหลดและติดตั้ง

1. **เข้าสู่ระบบ GitHub** เปิดหน้าผลการสร้าง แล้วเลื่อนลงไปที่ **Artifacts** เลือกชุดดาวน์โหลดให้ตรงกับเครื่อง ไม่ต้องเลือกไฟล์ที่ขึ้นต้นด้วย `evidence-`
2. แตก ZIP ที่ดาวน์โหลดมาเพื่อเข้าถึงตัวติดตั้ง ไม่ต้องใช้ Code > Download ZIP ซึ่งเป็นซอร์สโค้ดสำหรับผู้พัฒนา
3. **Windows:** เปิด `Stepfolio-Setup-1.1.1-x64.exe` แล้วทำตามขั้นตอนติดตั้ง จากนั้นเปิดโปรแกรมจาก Desktop หรือ Start
4. **Mac:** ตรวจชิปจาก Apple > About This Mac เลือก arm64 สำหรับ M series หรือ x64 สำหรับ Intel เปิด DMG แล้วลาก Stepfolio ไปยัง Applications จากนั้นเปิดจาก Applications

สำหรับ Windows มีตัวเลือก **Portable** (`Stepfolio-Portable-1.1.1-x64.exe`) เพื่อเปิดโดยไม่ติดตั้ง และ **ZIP ของโปรแกรม** (`Stepfolio-1.1.1-win-x64.zip`) ซึ่งต้องแตกอีกครั้งทั้งโฟลเดอร์ก่อนเปิด `Stepfolio.exe` และเก็บไฟล์ประกอบทั้งหมดไว้ด้วยกัน

ไฟล์ Actions artifacts มีระยะเวลาจัดเก็บ หากหมดอายุให้ผู้ดูแลสร้างแพ็กเกจใหม่ ผู้ที่ไม่มีบัญชี GitHub สามารถขอชุดติดตั้งจากผู้ดูแลได้ มีไฟล์ `SHA256SUMS-*.txt` ในแต่ละชุดสำหรับตรวจสอบไฟล์ดาวน์โหลด

ก่อนติดตั้ง ให้บันทึกโครงการ `.stepfolio` และปิด Stepfolio ที่เปิดอยู่ ตัวติดตั้งยังไม่มีลายเซ็นผู้เผยแพร่ / notarization ระบบอาจแจ้งเตือนผู้พัฒนาไม่ทราบชื่อ ควรใช้ไฟล์จาก repository นี้หรือผู้ดูแลที่เชื่อถือได้

## เริ่มใช้งาน

1. กด **เริ่มบันทึกการสาธิต** เลือกหน้าจอ และเลือกว่าจะเก็บการเลื่อนหน้าจอ / Enter / Tab / Escape หรือไม่
2. สาธิตตามปกติ โปรแกรมจะเก็บภาพหลังเหตุการณ์บนจอที่เลือก ควรเว้นให้หน้าจอเปลี่ยนเสร็จก่อนทำขั้นตอนถัดไป
3. กด **Stop** บนแถบลอย หรือ `Ctrl+Shift+S` (Windows) / `Cmd+Shift+S` (Mac)
4. เลือกภาพทางซ้าย เติมชื่อขั้นตอนและคำอธิบาย สลับภาพได้โดยรายการคงตำแหน่งเลื่อนเดิม
5. เพิ่มจุดเน้น กรอบ ไฮไลท์ และข้อความ แล้วจัดลำดับหรือลบภาพที่ไม่ต้องการ
6. ใส่ชื่อคู่มือ คำอธิบาย และผู้จัดทำในแท็บ **ข้อมูลคู่มือ**
7. กด **บันทึกโครงการ** เพื่อเก็บไฟล์ `.stepfolio` สำหรับแก้ไขต่อ และ **ส่งออก PDF** เพื่อแจกผู้อ่าน

ผู้ใช้งานตัวติดตั้งไม่ต้องติดตั้ง Node.js หรือใช้ Terminal

## แก้ไขภาพและจุดเน้น

- **＋ จุดเน้น / Step:** คลิกเพิ่มได้หลายจุดต่อภาพ เริ่มนับ 1 ใหม่ในแต่ละภาพ เลือกรายการแล้วใช้ปุ่ม ↑ / ↓ เพื่อจัดลำดับ
- **กรอบสี่เหลี่ยม / ไฮไลท์:** เลือกเครื่องมือแล้วลากบนภาพเพื่อกำหนดพื้นที่
- **ข้อความ:** พิมพ์ข้อความ เลือกขนาด กดเครื่องมือข้อความ แล้วคลิกบนภาพ
- เลือกรายการเพื่อเปลี่ยนสี แก้ข้อความ กด **ย้ายรายการที่เลือก** แล้วคลิกตำแหน่งใหม่ หรือ **ลบรายการที่เลือก**
- กด Esc เพื่อออกจากเครื่องมือ ภาพต้นฉบับยังอยู่ครบ เครื่องหมายทั้งหมดบันทึกในโครงการและแสดงใน PDF
- รายการภาพด้านซ้ายคงตำแหน่งเลื่อนเมื่อเลือกภาพ แก้ชื่อ/คำบรรยาย จัดลำดับ และลบ/ย้อนกลับ เมื่อเปิดอีกโครงการจะเริ่มรายการที่ด้านบน

## คู่มือภาษาไทย

[ดาวน์โหลดคู่มือ PDF พร้อมภาพประกอบ 12 หน้า](output/pdf/Stepfolio-User-Guide-TH.pdf) ครอบคลุมการติดตั้ง การบันทึก การแก้ไขภาพ การบันทึกโครงการ และส่งออก PDF เปิดคู่มือที่รวมมากับโปรแกรมได้จาก **ช่วยเหลือ > คู่มือภาษาไทย (PDF)**

## สิทธิ์และการบันทึก

- Windows 10/11 แบบ 64 บิต (x64); macOS 12 ขึ้นไป แยก Apple Silicon และ Intel
- บน Mac ให้เปิด **Screen Recording / Screen & System Audio Recording** และ **Accessibility** ใน System Settings > Privacy & Security สำหรับ Stepfolio ที่ติดตั้งใน Applications แล้วปิดและเปิดโปรแกรมใหม่หากระบบร้องขอ
- **Pause / Resume:** พักหรือบันทึกต่อ ภาพที่รอประมวลผลก่อน Pause อาจยังถูกเก็บ
- **＋ ภาพ** หรือ `Ctrl/Cmd+Shift+Space`: เก็บภาพเพิ่มเองโดยวางเมาส์บนจอที่เลือก แถบลอยจะซ่อนชั่วคราวระหว่างจับภาพ
- เลือกจังหวะจับภาพหลังเหตุการณ์ได้ 0.25, 0.6 หรือ 1 วินาที การเลื่อนหน้าจอจำกัดประมาณหนึ่งภาพต่อวินาที
- รองรับ 500 ขั้นตอนต่อโครงการ ภาพกว้างเกิน 2560 พิกเซลจะถูกย่อ โปรแกรมนี้เก็บภาพตามเหตุการณ์ ไม่ใช่วิดีโอทุกเฟรม

## บันทึกโครงการและกู้คืน

`.stepfolio` รวมภาพ ข้อความ ลำดับขั้นตอน และเครื่องหมายไว้ในไฟล์เดียว เปิดผ่าน **เปิดโครงการ** เพื่อแก้ไขต่อ ใช้ **บันทึกเป็น…** เมื่อต้องการเก็บอีกสำเนา

โปรแกรมเก็บฉบับกู้คืนล่าสุดในโฟลเดอร์ข้อมูลแอป:

- Windows: `%APPDATA%/Stepfolio/recovery.stepfolio`
- Mac: `~/Library/Application Support/Stepfolio/recovery.stepfolio`

ชื่อโฟลเดอร์อาจเป็น `stepfolio` ในโหมดพัฒนา ฉบับกู้คืนมีเพียงงานล่าสุด การเริ่มหรือเปิดโครงการอื่นอาจเปลี่ยนฉบับกู้คืน จึงควรบันทึกแต่ละงานเป็นไฟล์แยก

ไม่มีการอัปโหลดภาพหรือคำบรรยาย แต่สิ่งที่มองเห็นบนหน้าจอจะติดอยู่ในภาพ ควรตรวจข้อมูลส่วนตัวก่อนแบ่งปัน ไฟล์โครงการไม่ได้เข้ารหัส

## สำหรับผู้พัฒนา

```sh
npm ci
npm start
npm test
node scripts/scroll.cjs
node scripts/smoke.cjs
node scripts/pdf-large.cjs
npm run dist:win
npm run dist:mac -- --arm64
npm run dist:mac -- --x64
```

- `scripts/scroll.cjs` ทดสอบรายการ 70 ภาพ: เลือกภาพช่วงท้าย แก้ชื่อ/คำบรรยาย จัดลำดับ ลบ/ย้อนกลับ เปลี่ยนแท็บ เลื่อนด้วยผู้ใช้ และเปิดอีกโครงการ
- `scripts/smoke.cjs` ทดสอบเครื่องหมายหลายรายการ บันทึก/เปิดโครงการ การกู้คืน และ PDF ใน Electron
- `scripts/pdf-large.cjs` ทดสอบ PDF ภาพขนาดใหญ่ การส่งออกซ้ำ และการล้างไฟล์ชั่วคราวเมื่อเกิดข้อผิดพลาด
- `.github/workflows/build.yml` สร้างและทดสอบแอปที่แพ็กแล้วบน Windows x64, Mac arm64 และ Mac Intel เก็บตัวติดตั้งและ checksum ใน Actions artifacts โดยไม่เผยแพร่ Release อัตโนมัติ
- เริ่ม build ได้ด้วย workflow_dispatch, tag `v*` หรือ push main ที่แก้ package.json, package-lock.json หรือ workflow นี้
- Windows CI ติดตั้ง Setup จริงก่อนทดสอบ และตรวจ native recording เพิ่มเติม การบันทึกบน Mac ต้องตรวจหลังอนุญาตสิทธิ์บนเครื่องผู้ใช้ ผลทดสอบไม่ครอบคลุมฮาร์ดแวร์และการตั้งค่าหลายจอทุกแบบ
